# 🏗️ 02. Иерархия: Проекты → Модули → Прогресс %

Основа всей системы — трехуровневая чистая структура:
```
Workspace (Организация)
   └── Project (Проект / Продукт)
         └── Module (Функциональный модуль)
               └── Task (Атомарная задача на Канбане)
```

---

## 1. Концепция Модулей (Почему не просто плоские задачи?)
В Битриксе задачи свалены в одну кучу или привязаны к сложным группам/проектам с кучей лишних настроек. В нашей системе:
* **Проект** — это макро-цель (например, *"Запуск MVP Toguz Hub"*).
* **Модуль** — это логическая подсистема продукта (например, *"Аутентификация"*, *"Голосовой движок WebRTC"*, *"Канбан-доска"*, *"Биллинг"*).
* Пользователь всегда видит: **какой модуль тормозит весь проект, а какой уже закрыт на 100%**.

```mermaid
graph TD
    P[Проект: Toguz Hub MVP — 74% Done]
    P --> M1[Модуль: Auth & Users — 100%]
    P --> M2[Модуль: Kanban & Tasks — 85%]
    P --> M3[Модуль: Voice Lounges — 60%]
    P --> M4[Модуль: Soundboard & Fun — 40%]
    
    M2 --> T1[Задача: Drag-n-Drop карточек (Done)]
    M2 --> T2[Задача: Расчет горящих дедлайнов (Done)]
    M2 --> T3[Задача: Оптимизация анимаций (In Progress)]
```

## 2. Алгоритм расчета прогресса (% Completion)

Прогресс каждого модуля и всего проекта рассчитывается автоматически в реальном времени при перемещении карточек задач.

### А. Прогресс Модуля
Каждая задача имеет статус:
* `BACKLOG` / `TODO` = 0%
* `IN_PROGRESS` = 20% (опционально для расчета вклада в разработку, либо 0% до завершения)
* `REVIEW` = 80% (код написан, тестируется)
* `DONE` = 100%

По умолчанию для стартапа принята бинарная прозрачная модель:
$$ \text{Module Progress (\%)} = \left( \frac{N_{\text{DONE}}}{N_{\text{TOTAL}}} \right) \times 100 $$
Где:
* $N_{\text{DONE}}$ — количество задач в колонке `DONE`.
* $N_{\text{TOTAL}}$ — общее число активных задач в модуле.
* *Edge-case*: Если в модуле $N_{\text{TOTAL}} = 0$, прогресс отображается как `0%` со статусом *"Empty Module / Not Started"*.

### Б. Прогресс Проекта
Прогресс всего проекта вычисляется как средневзвешенное значение прогресса всех его модулей:
$$ \text{Project Progress (\%)} = \frac{1}{M} \sum_{i=1}^{M} \text{Module Progress}_i $$
Либо с учетом весов сложности (если у модулей задан вес $w_i \in [1..5]$):
$$ \text{Project Progress (\%)} = \frac{\sum_{i=1}^M (w_i \times \text{Module Progress}_i)}{\sum_{i=1}^M w_i} $$

## 3. Визуальное представление (Fancy & Modern Look)

Чтобы интерфейс выглядел современно и молодежно (Gen Z aesthetic), прогресс не должен быть унылой серой полоской:
1. **Неоновый градиент прогресс-бара**:
   - `0% - 30%`: Кибер-розовый / коралловый градиент (`#FF2A55` → `#FF708F`).
   - `31% - 70%`: Неоновый янтарно-фиолетовый (`#FFAA00` → `#8B5CF6`).
   - `71% - 99%`: Неоновый индиго / ультрамарин (`#6366F1` → `#38BDF8`).
   - `100%`: Чистый изумрудный глоу (`#10B981`) с иконкой галочки и микро-анимацией конфетти при первом переходе в 100%.
2. **Radial Progress Rings (Круговые индикаторы)**:
   - В карточке модуля на титульной странице процент выводится внутри кругового кольца (SVG ring с `stroke-dashoffset` анимацией).
3. **Статусные бейджи**:
   - `🔥 Burning`: если внутри модуля есть хотя бы одна задача с дедлайном < 24ч.
   - `⚡ In Active Flow`: если прямо сейчас в модуле кто-то перетаскивает задачи или привязан к голосовой комнате.
   - `✅ Shipped`: модуль закрыт на 100%.

---

## 4. Быстрые действия с модулями
- **Связка с чатом**: Клик на значок `#` в карточке модуля мгновенно открывает привязанный чат [[05_Chats_&_Realtime_Collab]].
- **Фильтр Канбана**: Клик по названию модуля фильтрует общую канбан-доску, оставляя только задачи этого блока.
- **Быстрое добавление**: Кнопка `+ Task` прямо внутри карточки модуля на дашборде.
